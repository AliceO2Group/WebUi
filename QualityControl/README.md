## QCG - Web Graphical User Interface for O<sup>2</sup> Quality Control

QCG is a **Web-based graphical user interface (GUI)** designed for [**O<sup>2</sup> Quality Control**](https://github.com/AliceO2Group/QualityControl). It provides an intuitive interface for managing and visualizing quality control data in the context of the O<sup>2</sup> project.
